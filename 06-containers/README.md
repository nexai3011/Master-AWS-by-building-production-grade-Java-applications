# Containers on AWS

Containerize Java applications and deploy them using AWS-native patterns.

## Topics

- Docker basics
- ECR
- ECS
- Fargate
- ECS with Spring Boot

## Goal

Understand how Java applications are packaged, shipped, and run in container platforms.
