# Roadmap

## Phase 1 — AWS Fundamentals

- AWS account setup and billing controls
- IAM, roles, policies, and least privilege
- Regions, Availability Zones, and VPC basics
- EC2 and networking fundamentals
- S3 and storage security
- CloudWatch and basics of monitoring

## Phase 2 — Java on AWS

- Deploy a Spring Boot app on EC2
- Spring Boot integration with RDS PostgreSQL
- Spring Boot integration with S3
- Spring Boot integration with Secrets Manager
- Spring Boot metrics and CloudWatch logs

## Phase 3 — Databases and Storage

- RDS PostgreSQL and connection pooling
- Aurora and read replicas
- DynamoDB patterns for Java applications
- Redis / ElastiCache for caching and sessions
- S3 presigned URLs and multipart uploads

## Phase 4 — Messaging and Event-Driven Systems

- SQS producer/consumer design
- SNS for fan-out patterns
- EventBridge for orchestration
- Kafka fundamentals and MSK
- Spring Cloud Stream integration

## Phase 5 — Containers and Orchestration

- Docker fundamentals for Java apps
- ECR image lifecycle and tagging
- ECS and Fargate deployment
- EKS basics and production patterns
- Blue-green and rolling deployment strategies

## Phase 6 — Serverless

- Lambda for Java workloads
- API Gateway for REST APIs
- Event-driven microservices
- Step Functions for workflows
- Lambda + S3 + SQS patterns

## Phase 7 — Security and Reliability

- IAM least privilege and restricted access
- KMS, encryption at rest and in transit
- Secrets Manager and configuration hygiene
- WAF, ALB, and network security
- Multi-AZ and failover patterns

## Phase 8 — CI/CD and Infrastructure as Code

- GitHub Actions pipelines
- Terraform for AWS infrastructure
- CDK for Java-based IaC
- Environment promotion strategies
- Deployment automation and rollback patterns

## Phase 9 — Observability and Performance

- JVM profiling and memory troubleshooting
- CloudWatch dashboards and metrics
- OpenTelemetry and traces
- Latency investigation and database bottleneck analysis
- Load testing and performance tuning

## Phase 10 — Production Architecture

- Multi-tier architecture design
- Auto Scaling and load balancers
- Resilience patterns and retries
- Circuit breakers and timeouts
- Capacity planning and performance sizing

## Phase 11 — System Design

- URL shortener
- file upload service
- order management platform
- payment platform
- ride booking and healthcare architecture

## Phase 12 — Interview Preparation

- scenario-based AWS interview questions
- distributed systems debugging
- database and JVM investigation
- pain point analysis for production systems
- architecture review and trade-off communication

---

## Suggested order of study

1. Getting started and IAM basics
2. EC2 and Spring Boot deployment
3. RDS and S3 integration
4. Messaging with SQS and SNS
5. Docker and ECS
6. Security and CloudWatch
7. Terraform and GitHub Actions
8. Observability and performance tuning
9. Microservices and event-driven design
10. System design and interview scenarios
